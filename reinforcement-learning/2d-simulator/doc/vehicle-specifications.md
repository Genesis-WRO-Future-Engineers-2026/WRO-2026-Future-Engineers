## 概要

本プロジェクトで使用する実機は、タミヤ製の1/10スケール電動RCカー「TT-02」シャーシです。
縦置きモーター・シャフトドライブ方式の4WDモデルで、初心者向けの「ファーストトライ」として部分組み立て済みキットとして提供されています。

**製品情報:**
- 製品番号: 57986
- メーカー: 株式会社タミヤ
- 公式ページ: https://www.tamiya.com/japan/products/57986/index.html

## スケーリング分析

### 寸法の比較

**実機を基準とした場合（1/10スケール）:**

```
実機TT-02:
  全長: 479mm
  全幅: 188mm
  ホイールベース: 257mm
  重量: 1199g (バッテリー除く)

シミュレーション:
  全長: 400mm (83.5% of 実機)
  全幅: 200mm (106.4% of 実機)
  ホイールベース: 280mm (109.0% of 実機)
  重量: 1000g (83.4% of 実機)
```

**結論:**
- 現在のシミュレーションは実機とほぼ同スケールですが、細部に差異があります
- 特にホイールベースが長く、質量が軽いため、実機より機敏に動く可能性があります
- 全長が短いため、旋回時の挙動が実機と異なる可能性があります

### 車両の対角線半径

**実機TT-02の場合:**
```
対角線 = sqrt(479^2 + 188^2) = 514.7 mm
半径 = 514.7 / 2 = 257.4 mm
```

**シミュレーション（現在）:**
```
対角線 = sqrt(400^2 + 200^2) = 447.2 mm
半径 = 447.2 / 2 = 223.6 mm
```

**現在の衝突判定距離（`COLLISION_DISTANCE = 0.22m`）は、シミュレーション車両の対角線半径とほぼ一致しています。**

## 実機への転移を考慮した推奨事項

### 1. 寸法の正確化【推奨】

**推奨変更:**
```python
# src/env/vehicle.py

self.width = 0.188  # m (実機: 188mm)
self.length = 0.479  # m (実機: 479mm)
self.wheelbase = 0.257  # m (実機: 257mm)
```

**理由:**
- シミュレーションと実機の挙動を一致させる
- sim-to-realギャップを最小化
- 実機での転倒リスクを正確に再現
- 旋回半径を実機に合わせる

**期待される効果:**
```
旋回半径の変化:
  変更前: 0.28 / tan(0.5) = 0.51m
  変更後: 0.257 / tan(0.5) = 0.47m

→ 実機に近い旋回性能
```

---

### 2. 質量の調整【推奨】

**推奨変更:**
```python
# src/env/vehicle.py

self.mass = 1.4  # kg
# 内訳:
#   車体: 1199g
#   バッテリー (7.2V NiMH): 200-300g
#   合計: 約1400-1500g
```

**理由:**
- バッテリー重量を考慮
- 実機の慣性モーメントを正確に再現
- ブレーキング距離を実機に近づける
- 加速特性を実機に合わせる

**期待される効果:**
```
加速度の変化:
  F = ma より、a = F / m

  変更前: a = 20N / 1.0kg = 20 m/s²
  変更後: a = 20N / 1.4kg = 14.3 m/s²

→ 実機の加速度に近づく
```

---

### 3. 衝突判定距離の調整【オプション】

**推奨変更:**
```python
# src/env/minicar_env.py

# 実機の対角線半径に合わせる
COLLISION_DISTANCE = 0.26  # m (260mm、実機の半径257mm + 余裕3mm)
WALL_APPROACH_DISTANCE = 0.4  # m (400mm、より余裕を持たせる)
```

**理由:**
- 寸法を実機に合わせた場合、衝突判定も調整が必要
- 実機の対角線半径（257mm）に基づいた判定

**注意:** この変更は、上記1（寸法の正確化）を実施した場合に行います。

## まとめ

### 現状の課題

1. **寸法の不一致:**
   - 全長が実機より16.5%短い
   - ホイールベースが実機より9%長い
   - sim-to-realギャップの原因

2. **質量が軽い:**
   - バッテリー重量が未考慮
   - 実機より28.6%軽い
   - 慣性・加速・制動が実機と異なる

### 推奨アクション

**実機への転移を考慮する場合:**
1. 車両寸法を実機に合わせる（length, width, wheelbase）
2. 質量をバッテリー込みの重量に調整（1.4kg）
3. （オプション）衝突判定距離を調整

**現状のまま学習を進める場合:**
- シミュレーションでの学習は可能
- ただし、実機への転移時に再調整が必要
