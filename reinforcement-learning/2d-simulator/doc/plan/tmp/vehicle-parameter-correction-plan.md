# 車両パラメータ修正実装計画

**作成日:** 2025-12-10
**目的:** シミュレーション車両パラメータを実機（TAMIYA TT-02）に合わせる
**優先度:** 中（sim-to-realギャップの最小化）

---

## エグゼクティブサマリー

現在のシミュレーションは実機（TAMIYA TT-02）と以下の点で乖離があります：

| パラメータ | 現在値 | 実機値 | 差異 | 影響 |
|-----------|--------|--------|------|------|
| **全長** | 400mm | 479mm | -16.5% | ⚠️ 旋回半径、慣性 |
| **ホイールベース** | 280mm | 257mm | +8.9% | ⚠️ 旋回性能 |
| **質量** | 1.0kg | 1.4kg* | -28.6% | ⚠️⚠️ 加速、制動 |

*バッテリー込みの重量

**主要課題:**
1. **寸法の正確化**（実機と一致）- sim-to-realギャップの最小化
2. **質量の調整**（バッテリー込み）- 実機の物理特性を再現

## 現状分析

### 問題1: 車両寸法の不一致

**現在の設定:**
```python
# src/env/vehicle.py (59-62行目)
self.width = 0.2  # m (実機: 188mm → 6%大きい)
self.length = 0.4  # m (実機: 479mm → 16.5%小さい)
self.wheelbase = 0.28  # m (実機: 257mm → 8.9%大きい)
```

**影響:**
- 旋回半径が実機と異なる
- 狭い通路での挙動が異なる
- 衝突判定の範囲が不正確
- 全長が短いため、車両の慣性が実機と異なる

---

### 問題2: 質量が軽すぎる

**現在の設定:**
```python
# src/env/vehicle.py (61行目)
self.mass = 1.0  # kg
```

**実機の重量構成:**
```
車体本体: 1199g
7.2V NiMHバッテリー: 200-300g
合計: 約1400-1500g
```

**影響:**
- 加速度が実機より速い（約40%速い）
- 制動距離が実機より短い
- 慣性が異なるため、急カーブでの挙動が異なる
- 質量が軽いため、実機より機敏に動く

## 実装計画

### フェーズ1: 車両寸法の正確化【推奨】

**目的:** シミュレーションと実機の挙動を一致させる

#### 変更箇所

**vehicle.py（1箇所）**

```python
# src/env/vehicle.py (59-62行目)

# 変更前
self.width = 0.2  # m
self.length = 0.4  # m
self.wheelbase = 0.28  # m

# 変更後（実機TT-02の寸法に合わせる）
self.width = 0.188  # m (実機: 188mm)
self.length = 0.479  # m (実機: 479mm)
self.wheelbase = 0.257  # m (実機: 257mm、標準設定)
```

#### 期待される効果

**旋回半径の正確化:**
```
旋回半径 = wheelbase / tan(steering_angle)

変更前（wheelbase=0.28m）:
  最小旋回半径 = 0.28 / tan(0.5) = 0.51m

変更後（wheelbase=0.257m）:
  最小旋回半径 = 0.257 / tan(0.5) = 0.47m

→ 実機に近い旋回性能（約8%小回りになる）
```

**衝突判定の正確化:**
```
対角線半径（変更前）= sqrt(0.4^2 + 0.2^2) / 2 = 0.224m
対角線半径（変更後）= sqrt(0.479^2 + 0.188^2) / 2 = 0.257m

→ 実機の衝突範囲を正確に再現（約15%大きくなる）
```

### フェーズ2: 質量の調整【推奨】

**目的:** 実機の慣性・加速・制動を正確に再現

#### 変更箇所

**vehicle.py（1箇所）**

```python
# src/env/vehicle.py (61行目)

# 変更前
self.mass = 1.0  # kg

# 変更後（バッテリー込みの重量）
self.mass = 1.4  # kg (車体1.2kg + バッテリー0.2kg)
```

#### 期待される効果

**加速度の変化:**
```
F = ma より、a = F / m

変更前: a = 20N / 1.0kg = 20 m/s²
変更後: a = 20N / 1.4kg = 14.3 m/s²

→ 実機の加速度に近づく（約30%減少）
```

**制動距離の変化:**
```
運動エネルギー: E = (1/2) * m * v²

変更前（1.0kg、速度10m/s）: E = 50J
変更後（1.4kg、速度10m/s）: E = 70J

→ より長い制動距離が必要（約40%増加）
→ 実機の挙動に近い
```

**慣性モーメントの変化:**
```
質量が1.4倍になることで、慣性モーメントも増加
→ 旋回開始時の反応が遅くなる
→ 旋回中の安定性が向上
→ 実機の挙動に近い
```

---

### フェーズ3: 衝突判定距離の調整【オプション】

**目的:** 実機の対角線半径に合わせた衝突判定

#### 変更箇所

**minicar_env.py（1箇所）**

```python
# src/env/minicar_env.py (23-24行目)

# 変更前
COLLISION_DISTANCE = 0.22  # m (220mm)
WALL_APPROACH_DISTANCE = 0.3  # m (300mm)

# 変更後（実機の対角線半径に合わせる）
COLLISION_DISTANCE = 0.26  # m (260mm、実機半径257mm + 余裕3mm)
WALL_APPROACH_DISTANCE = 0.4  # m (400mm、より余裕を持たせる)
```

**注意:** この変更は、フェーズ1（車両寸法の正確化）を実施した場合に行います。
