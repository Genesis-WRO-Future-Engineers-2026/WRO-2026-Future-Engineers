# LiDARセンサー配置に関する調査レポート

**調査日:** 2025-12-10
**調査目的:** 5本のLiDARセンサーを使用する場合の最適な配置を文献調査により決定する

---

## エグゼクティブサマリー

### 結論：前方集中型配置を推奨

**推奨配置:** `-60°, -30°, 0°, +30°, +60°` （前方120度カバー）

**理由:**
1. 車両は前方に進むため、前方の障害物検知が最も重要
2. 深層強化学習の研究で、前方向きのFOV最適化が98%の成功率を達成
3. 360度均等配置よりも、タスクに特化した配置の方が学習効率が高い
4. 後方の情報は速度と角速度から間接的に推測可能

---

## 文献調査の主要な知見

### 1. 深層強化学習におけるLiDAR配置の影響

**論文:** "The Impact of LiDAR Configuration on Goal-Based Navigation within a Deep Reinforcement Learning Framework" (2024)

**重要な発見:**
- **最適FOV（視野角）の計算:** センサーの幅と障害物との最小安全距離を使用してFOVを計算
- **成功率:** 計算されたFOVを使用した構成で**98%の成功率**を達成
- **ビーム密度:** 大量のビーム数は必ずしも必要ではなく、静的環境でのナビゲーションには適切なFOVと密度が重要
- **前方重視:** 前方の静的障害物を避けることに最適化されたFOV設定が重要

**教訓:** 360度をカバーする必要はなく、タスクに応じた最適なFOVを選択すべき

---

### 2. 自動運転車両におけるLiDAR配置の最適化

**論文:** "An Optimal LiDAR Configuration Approach for Self-Driving Cars" (ResearchGate)

**重要な発見:**
- **RoI（関心領域）の分割:** 6つのゾーンに分類（コアRoIと拡張RoI）
- **配置オプション:** フロントグリル内部、フロントガラス後方、または屋根上の3つの選択肢
- **前方向き構成:** 狭い前方視野の構成が自動運転車両に適している
- **コスト考慮:** 360度カバーのLiDARは高価で、小規模アプリケーションには不向き

**教訓:** 前方向き（forward-facing）の構成が、コストと性能のバランスが良い

---

### 3. 2D LiDARによる障害物回避アルゴリズム

**論文:** "The obstacle detection and obstacle avoidance algorithm based on 2-D lidar" (IEEE)

**重要な発見:**
- **セクター分割:** 360度を複数のセクターに分割（例: 18セクター × 20度）
- **前方セクター最適化:** 前方のセクターに重点を置いた処理
- **最小コスト関数:** 前方角度と速度を最小コスト関数で生成
- **角度解像度:** 1度刻みの高密度スキャン例（-5° to +185°、191点）

**教訓:** セクターベースの処理では、前方に多くのセクターを割り当てることが一般的

---

### 4. モバイルロボットのナビゲーション手法

**論文:** "Mobile Robot Navigation Based on Deep Reinforcement Learning with 2D-LiDAR Sensor" (IEEE)

**重要な発見:**
- **PPOの使用:** Proximal Policy Optimization（PPO）がLiDARベースのナビゲーションで有効
- **Sparse LiDAR:** スパース（疎）なレーザー信号でもマップレスナビゲーションが可能
- **FOV設定:** ロボットのサイズと最小安全距離からFOVを決定
- **コスト削減:** 広いFOVを持つLiDARは高価なため、最小限の構成が求められる

**教訓:** スパースなセンサーでも適切なアルゴリズムで高い性能を達成可能

---

### 5. Gap-Based障害物回避手法

**論文:** "Obstacle Avoidance and Path Planning Methods for Autonomous Navigation" (PMC)

**重要な発見:**
- **Follow the Gap Method (FGM):** 利用可能な隙間を角度で表現
- **ギャップ配列:** ロボット周囲の利用可能な隙間サイズを角度形式で提供
- **最小構成:** 少数のセンサーで隙間検出が可能
- **安全距離:** ロボットの仕様に基づいて閾値距離を設定（例: 20 cm）

**教訓:** 隙間ベースの手法では、前方の数本のレイで十分

## 5本LiDARの推奨配置案

### **案1: 前方120度カバー（最推奨）**

```
配置: -60°, -30°, 0°, +30°, +60°
```

```
        0° (前方)
         |
    -30° | 30°
      \  |  /
   -60°\|/ 60°
    ----車----
```

**メリット:**
- ✅ 前方120度を30度間隔で均等にカバー
- ✅ 車両が前進する方向の障害物を細かく検知
- ✅ 左右の壁との距離を正確に把握
- ✅ 狭い通路でも左右の壁を同時に検知可能
- ✅ 前方の複雑な障害物形状を認識可能

**デメリット:**
- ⚠️ 後方は完全にブラインドスポット
- ⚠️ 真横（±90度）の障害物を直接検知できない

**適用シーン:**
- 前進がメインのレース環境
- チェックポイントを順番に通過するタスク
- 後退が不要なコース

---

### **案2: 前方180度カバー**

```
配置: -90°, -45°, 0°, +45°, +90°
```

```
    -45°  0°  45°
      \   |   /
   -90°\  |  / 90°
    ----車----
```

**メリット:**
- ✅ 前方180度（半球）をカバー
- ✅ 真横の障害物も検知可能
- ✅ 急カーブでも外側の壁を検知
- ✅ 横からの障害物接近を検知

**デメリット:**
- ⚠️ 後方180度はブラインドスポット
- ⚠️ 前方の解像度が案1より粗い（45度間隔）

**適用シーン:**
- 急カーブが多いコース
- 横方向への回避動作が必要な環境
- 狭い通路での左右確認が重要な場合

---

### **案3: 前方90度高密度カバー**

```
配置: -45°, -22.5°, 0°, +22.5°, +45°
```

```
      -22.5° 0° 22.5°
         \   |   /
    -45° \  |  / 45°
      ----車----
```

**メリット:**
- ✅ 前方90度を22.5度の高密度でカバー
- ✅ 正面の障害物形状を最も詳細に把握
- ✅ 狭い隙間の検知に有利
- ✅ 精密な操舵制御が可能

**デメリット:**
- ⚠️ 視野が最も狭い（90度のみ）
- ⚠️ 急カーブでのコーナー外側の壁を見失いやすい
- ⚠️ 横方向の障害物を検知できない

**適用シーン:**
- 直線が多いコース
- 狭い隙間を抜けるタスク
- 高速走行が求められる環境

---

### **案4: 360度均等配置（当初案）**

```
配置: 0°, 72°, 144°, 216°, 288°
```

```
        0°
         |
    288° | 72°
      \  |  /
       \ | /
   216°-車-144°
```

**メリット:**
- ✅ 全方向をカバー
- ✅ 後方の障害物も検知可能
- ✅ 車両の周囲360度の状況を把握

**デメリット:**
- ❌ 前方の解像度が低い（72度間隔）
- ❌ 前方の障害物形状を詳細に把握できない
- ❌ 重要な前方の情報密度が不足
- ❌ 後方の情報は速度・角速度から推測できるため冗長

**適用シーン:**
- 後退が頻繁に必要な環境
- 全方向から障害物が接近する環境
- オムニディレクショナル（全方向移動）ロボット

## 推奨配置の決定プロセス

### ステップ1: タスク要件の分析

**ミニカーレースの特性:**
- ✅ 前進がメインの動作
- ✅ 後退は基本的に不要
- ✅ チェックポイントを順番に通過
- ✅ 前方の壁や障害物を回避しながら進む
- ✅ コースには直線とカーブが混在

### ステップ2: 文献調査からの示唆

**深層強化学習の研究:**
- 前方向きのFOV最適化で98%成功率
- 全方向カバーは不要
- タスクに特化した配置が効率的

**自動運転の研究:**
- 前方180度カバーが一般的
- コストと性能のバランスで前方重視

**障害物回避の研究:**
- セクター分割では前方に多くのセクター
- Gap-basedメソッドは前方の隙間を検知

### ステップ3: 最終推奨

**第1候補: 案1（前方120度カバー）**
- 配置: `-60°, -30°, 0°, +30°, +60°`
- 理由: 前方を細かくカバーしつつ、左右の壁も検知可能

**第2候補: 案2（前方180度カバー）**
- 配置: `-90°, -45°, 0°, +45°, +90°`
- 理由: 急カーブでも対応可能な広い視野

**第3候補: 案3（前方90度高密度）**
- 配置: `-45°, -22.5°, 0°, +22.5°, +45°`
- 理由: 直線コースや高速走行に最適

## 追加の提案: 動的FOV調整

### アイデア
速度や状況に応じてFOVを動的に調整する

**例:**
- **低速時（< 1.0 m/s）:** 広いFOV（180度）で周囲を確認
- **高速時（> 2.0 m/s）:** 狭いFOV（90度）で前方に集中
- **カーブ中:** 操舵角に応じてFOVを傾ける

**実装:**
```python
# 速度ベースのFOV調整
speed = state["speed"]
if speed < 1.0:
    fov = 180  # 広い視野
elif speed > 2.0:
    fov = 90   # 狭い視野
else:
    fov = 120  # 中間
```

**メリット:**
- 状況に応じた最適な情報を取得
- 学習の収束が早い可能性

**デメリット:**
- 実装が複雑
- 観測空間が状態依存になる

## まとめ

### 最終推奨: 案1「前方120度カバー」

**配置:** `-60°, -30°, 0°, +30°, +60°`

**理由:**
1. 文献調査で前方向きFOVの有効性が実証されている
2. ミニカーレースのタスク特性（前進メイン）に最適
3. 左右の壁検知も可能で、狭い通路に対応
4. 360度均等配置より情報密度が高く学習効率が良い
5. コストと性能のバランスが最良

1. 案1で実装を進める
