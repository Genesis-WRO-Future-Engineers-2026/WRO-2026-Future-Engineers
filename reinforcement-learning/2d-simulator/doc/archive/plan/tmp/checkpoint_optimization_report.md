## 3. 修正内容

### 3.1 チェックポイント再配置

| CP | 修正前 | 修正後 | 変更理由 |
|----|--------|--------|----------|
| CP2 | `[4.0, 7.0]` | `[5.0, 6.5]` | コース内の自然な走行ルート上に移動 |
| CP3 | `[7.0, 5.0]` | `[8.5, 5.0]` | CP1→CP3ショートカット防止 |
| CP4 | `[9.5, 4.5]` | `[10.5, 3.8]` | より戦略的な配置、CP3→CP5ショートカット防止 |
| CP5 | `[8.3, 2.2]` | `[10.0, 2.3]` | ゴールへの自然な流れ |

## 4. 期待される効果

### 4.1 学習への影響

1. **CP2通過率の向上**
   - 位置が走行ルート上に移動 → 偶然の通過確率UP
   - チェックポイント報酬(+200)を獲得しやすくなる

2. **探索の効率化**
   - ショートカットが不利になる → 正規ルートの学習が促進
   - より安定した報酬獲得パターンの確立

3. **戦略的な走行**
   - 全チェックポイントを通過するルートが最適解に
   - 壁衝突リスクを減らした安全な走行の学習
