# 技術スタックとライブラリ選定

## 開発環境

- **Python**: 3.8以上（3.9推奨）
- **OS**: Linux/macOS/Windows対応（開発はLinux推奨）
- **エディタ**: VSCode推奨（デバッグ設定含む）

## コア依存ライブラリ

### 物理エンジン

#### Box2D (PyBox2D) - **採用**
```
pybox2d==2.3.10
```

**選定理由:**
- 2D物理演算に特化、軽量で高速
- 車両の動力学シミュレーションに最適
- ドキュメントが豊富
- Gymの`CarRacing-v0`でも使用実績あり

**代替案:**
- pymunk: より高機能だが、本プロジェクトには過剰

### 強化学習フレームワーク

#### PyTorch - **採用**
```
torch==2.0.0
torchvision==0.15.0
```

**選定理由:**
- デバッグが容易（動的計算グラフ）
- PyTorchベースのRL実装例が豊富
- Raspberry Piへのデプロイも可能（ONNX経由）

**代替案:**
- TensorFlow: 静的グラフで最適化しやすいが、デバッグが難しい

#### Stable-Baselines3 - **不採用（参考実装として利用）**

**不採用理由:**
- 学習プロセスの詳細制御が必要
- Domain Randomizationとカリキュラム学習の統合
- カスタマイズ性を重視し、PPOをスクラッチ実装

**活用方法:**
- 実装の参考として利用
- 初期プロトタイプの検証用

## 開発ツール

### バージョン管理
- **Git**: ソースコード管理
- **GitHub**: リモートリポジトリ
- **Git LFS**: 学習済みモデルの管理（オプション）

### CI/CD
- **GitHub Actions**: 自動テスト実行
- 設定ファイル: `.github/workflows/test.yml`

## ハードウェア要件

### 開発・学習環境
- **CPU**: 4コア以上推奨
- **RAM**: 8GB以上
- **GPU**: 不要（2Dシミュレーションは軽量）
  - あれば学習が高速化（CUDA対応GPU）
- **ストレージ**: 10GB以上

### 実機環境
- **Raspberry Pi 4**: 4GB以上
- **OS**: Raspberry Pi OS (64-bit)
- **Python**: 3.9以上

## バージョン管理方針

- **セマンティックバージョニング**: MAJOR.MINOR.PATCH
- **タグ付け**: 各マイルストーン達成時
- **ブランチ戦略**:
  - `main`: 安定版
  - `develop`: 開発版
  - `feature/*`: 機能追加
  - `fix/*`: バグ修正

## ライブラリ更新ポリシー

- **マイナーバージョン**: 定期的に更新
- **メジャーバージョン**: 慎重に評価後更新
- **セキュリティパッチ**: 即座に適用
